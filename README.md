# Data Analyst Internship – Task 4

## Interactive Sales & Profit Dashboard

This project focuses on creating an interactive business dashboard using **Tableau** and the **Sales Superstore dataset**.

### Objectives
- Analyze Sales and Profit
- Track monthly sales trends
- Identify top products
- Compare categories and regions
- Analyze customer segments
- Understand Discount vs Profit

### Tools Used
- Tableau
- Sales Superstore Dataset
- GitHub
- PowerPoint

### Dashboard KPIs
- Total Sales
- Total Profit
- Total Orders
- Profit Margin

### Visualizations
- Monthly Sales Trend
- Sales by Category
- Profit by Category
- Sales by Region
- Top 10 Products
- Sales vs Profit
- Discount vs Profit
- Sales by Segment

### Interactive Features
- Year Filter
- Region Filter
- Category Filter
- Segment Filter
- Interactive Charts and Tooltips

### Deliverables
- Tableau Dashboard
- Dataset
- Dashboard Screenshots
- PPT Presentation
- README.md

## Conclusion

The dashboard provides an interactive view of business sales and profitability and helps stakeholders make data-driven decisions.
